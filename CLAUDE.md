# triagelab

Static triage toolkit for **synthetic** lab samples, used as the demo project for the
"Building Smarter Workflows" Claude training.

## Safety rule (non-negotiable)

This repository never contains real malicious code. Everything under `fixtures/samples/`
is generated by `fixtures/generate_samples.py` and is inert ASCII plus random padding.
If a task would require obtaining, writing, or executing real malware, stop and say so.

## Build and test

- Install: `uv sync`
- Test: `uv run pytest -q` (must pass before any change is considered done)
- Lint: `uv run ruff check src tests`
- Regenerate samples: `uv run python fixtures/generate_samples.py`
- Triage one file: `uv run triagelab scan fixtures/samples/injector_stub.bin`
- Triage a directory: `uv run triagelab batch fixtures/samples`
- Dashboard: `uv run --extra web uvicorn web.app:app --reload --port 8000`

## Layout

- `src/triagelab/features.py` - entropy, strings, hashes. Pure stdlib, keep it dependency-free.
- `src/triagelab/rules.py` - indicator rules. Rule IDs are `TL0NN` and must stay unique.
- `src/triagelab/scoring.py` - deterministic 0-100 risk score. Tests pin exact numbers.
- `src/triagelab/report.py` - report dict, Markdown rendering, file output.
- `src/triagelab/cli.py` - argparse entry point (`scan`, `report`, `batch`).
- `web/app.py` - FastAPI dashboard over `reports/*.json`.

## Conventions

- The core package stays dependency-free. Third-party imports belong in `web/` only.
- Every new rule needs: a unique `TL0NN` id, a category, a severity 1-5, and a test.
- Scoring changes must update `tests/test_scoring.py` in the same change - the exact
  numbers are the contract, not an implementation detail.
- Never edit files under `fixtures/samples/` by hand. Change the generator and re-run it.
  (A PreToolUse hook enforces this, so a direct edit will be blocked.)
- Reports in `reports/` are generated output. Never hand-edit them.

# Compact instructions

When compacting, keep: the current task, failing test output, and any decision about
rule semantics or scoring weights. Drop: raw file listings, full string dumps from
triaged samples, and verbose pytest passes.
